# OSS Workshop - NIT Warangal

Practice repo for your first pull request.

## Your task

There's a bug in `hello.py`. Find it, fix it, and send a pull request.

1. Fork this repo
2. `git clone https://github.com/<your-username>/oss-workshop-nitw.git`
3. `cd oss-workshop-nitw`
4. `git checkout -b fix-bug`
5. Fix `hello.py`, then run `python3 hello.py` to check
6. `git add hello.py`
7. `git commit -m "Fix bug in hello.py"`
8. `git push origin fix-bug`
9. On GitHub, open a pull request to this repo
